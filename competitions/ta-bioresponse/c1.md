## 동일성 확인에 쓸 값

- 피처 배열은 작업 디렉터리에 없음. 최종 노드의 실행 출력도 없어서, **같은 aug 를 쓰는 부모 노드 66e16ce3** 의 기록을 씀: `aide.verbose.log` 5,409~5,410줄 "lgb CV AUC 0.8563964612084081", "lgb_aug CV AUC 0.8548138808094561" (seed 3개, 그 노드의 NS = 3)
- 확인 (로컬, 에이전트 코드는 실행하지 않음): 같은 fold (`StratifiedKFold(5, shuffle, 42)`) · LightGBM 설정 · seed 0~2 를 우리 코드로
  - `lgb` (원본만) → 0.8563964612 (**기록과 같음**, 차 0) → LightGBM · fold 는 플랫폼 사이에 같음
  - `lgb_aug` (`f2.blocks`, fold 마다 PCA fit, `isbin` 은 train 전체) → 0.8547365 (차 −7.7e-5)
  - 차는 PCA 의 수치 차이로 봄: PCA 는 randomized SVD (sklearn `auto`). 같은 데이터에서 `svd_solver="full"` 로 바꾸면 0.8555765, randomized seed 1 이면 0.8554901 → 풀이 방식만 바꿔도 7~8e-4 움직임 (관찰한 차의 10배). numpy 2.5.4 (로컬) 대 2.3.4 (에이전트), Mac 대 Linux BLAS
- `f2.build` 의 33열 = train 전체 fit 의 `blocks` 와 같음 (train · test 둘 다)
