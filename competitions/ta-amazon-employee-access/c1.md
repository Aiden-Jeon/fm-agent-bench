## F2 후보와 뺄 것

- 최종 제출에서 **타깃 독립 + inductive-OK 인 블록은 원본 9 뿐**. 원본 9 는 F0 이라 F2 아님.
- `~f2` 후보 = 빈도 45 + nunique 72 = **117 열**. 전부 train+test 기준으로 셈 → 규칙 밖. train 만으로 다시 셀 때만 후보 (test 행의 값은 train 빈도, 없으면 0). 최종에서 몫은 LGB·LGB2 (0.8) 와 CB (0.2).
- 뺄 것:
  - TE 45 열 (`:61-82`): 타깃 인코딩. 1차 규칙 밖. 최종 LGB 의 가장 큰 입력 → **이 실행의 피처 이득 대부분은 TE 와 스택에서 나왔을 가능성이 큼** (C1 1차로는 재현 불가)
  - LR 스택 logit 2 (`:146-164`): OOF 정답으로 학습한 LR 예측. 타깃 의존
  - 쌍 조합 36 과 삼중 조합 28: 최종에서 타깃 독립 형태로 쓰이지 않음 (쌍 코드는 TE 키와 LR 입력, 삼중은 LR2 입력뿐). 1차에서 넣으면 최종에 없던 피처가 됨. (`~f2s` 로 "쌍 문자열만" 두는 것도 최종에 없던 피처 → 후보 아님)
  - 블렌드 무게 `(0.6, 0.2, 0.2, 0)` (`:210-226`): OOF 정답으로 고른 값 → 타깃 의존
- **R3 판정**:
  - (a) 외부 정보·할당: 없음
  - (b) 최종에 원본 밖 블록 있음 (빈도·nunique·TE·스택): 해당 없음
  - (c) "타깃 독립 + inductive-OK 블록이 최종에 남는가": **남지 않음**. 타깃 독립 블록 중 최종에 들어가는 것은 빈도·nunique 117 열뿐이고 train+test 기준이라 규칙 밖. 재-fit 후에는 117 열이 후보로 남음
  - 결론: train 으로만 다시 fit 해 117열을 후보로 둠 → (c) 안 걸림 (정함 (2026-11-18, 사용자)). 다시 fit 하지 않는 기준이었다면 (c) 로 Claude Code +cont (0.1093) 로 내려갔음
- 해석 주의: 이 실행의 CV 는 TE 와 스택 (타깃 의존) 이 대부분을 만든 값. C1 1차 F2 (117 열 재-fit 후) 는 에이전트 이득의 작은 부분만 봄. 블렌드 AUC 0.8903 은 무게를 같은 OOF 로 고른 값이라 낙관적 (에이전트 기록도 같음)
