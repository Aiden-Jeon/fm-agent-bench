## F2 후보와 뺄 것

- **F2 후보 1개:** `~f2` = z 6열 + P 32열 = **38열**. 이름 자리 `competitions/ta-qsar-fish-toxicity/features/f2.py` (아직 없음). 타깃 비의존, 학습 행만 fit → inductive OK.
- `~f2s` 는 두지 않음: z 는 원본의 단조 변환이라 CatBoost 에선 F0 와 같은 분할. TFM 에선 표준화만 다름.
- 같은 블록의 변형 (stable 의 raw 표준화 + P, refined 의 log 변형) 은 1차 후보에 안 넣음. 최종 몫 미확인.
- **뺄 것:**
  - 타깃 의존: OOF 잔차를 타깃으로 쓰는 ExtraTrees (`residual_submission.py:15`, `mix_submission.py:22`) → 스태킹. 뺌 (피처가 아님).
  - 정답 조회: 중복 행의 train 평균 섞기 (`residual_submission.py:16-19`, `mix_submission.py:26`, `refined_submission.py:29-32`) → 뺌.
  - 타깃 의존 kNN 잔차 N 과 보정 (`#252`, `#271`, `#285`, `#274`, `#288`) → 뺌.
  - 모델 쪽: SVR, kNN, ExtraTrees 설정, TabICL (자체 설치 TFM) → 피처 아님.
  - 섞기 무게 (0.7/0.3, .4/.25/.2/.15, g 조건) → 피처 아님.
