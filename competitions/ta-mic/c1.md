## F2 후보와 뺄 것

- **F2 후보 A (`~f2m`, 1차 후보):** 원본 111 + 결측 지시 17열 → 128열. 타깃 비의존, 학습 행만으로 지시 열을 정함 → inductive OK. 선형 성분의 몫을 트리·FM 입력으로 옮기는 것. 파일 자리 `competitions/ta-mic/features/f2m.py` (아직 없음).
- **F2 후보 B (`~f2lr`, 1차 아님):** 선형 성분의 입력 전체 (수치 17 중앙값·표준화 + 지시 17 + 범주 OneHot). 열 수가 크고 (수준 합, 미확인) TFM 상한을 넘을 가능성이 큼 → C1 규칙 6 (상한) 적용 대상.
- **뺄 것:**
  - Extra Trees 원인 모델: 최종에 안 들어감 (`Retained the reference model`). 피처가 아니라 모델.
  - 사망 보정 (기울기·절편을 OOF 타깃으로 맞춤): 타깃 의존 → 뺌.
  - 블렌드 무게 (XGB 0/.15/.30, 선형 C 와 무게 .10/.20/.30): OOF 로 고른 섞기 무게 → 피처 아님.
  - CatBoost 에 범주를 표시하지 않은 것 (`cat_features` 없음): 피처가 아니라 설정. 우리 GBDT 는 F0 의 `cat_cols` 94열을 그대로 씀. F2 의 `cat_cols` 를 빈 목록으로 두면 안 됨.
