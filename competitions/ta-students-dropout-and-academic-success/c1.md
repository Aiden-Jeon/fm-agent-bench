## F2 후보와 뺄 것

- `~f2s` = 원본 36 + 행별 파생 7 = **43 열**. 1차 규칙 안 (타깃 비의존, fit 없음). 최종 제출의 7 개 성분 (CB·LR·LGB·ET·MLP·LRS·HLGB) 이 받음.
- `~f2` = `~f2s` + 빈도 17 = **60 열**, 단 빈도는 train 만으로 셀 때만 후보 (test 에 없는 값은 0). 지금 값 (train+test 기준) 은 규칙 밖.
- 뺄 것:
  - 블렌드 무게 (`:371-408`), 스태킹 LR 메타 (`:410-426`), 온도 T (`:444-460`): OOF 정답으로 고른 값 → 타깃 의존 (사후 처리)
  - (고침 2026-11-18) 에이전트 `cat_cols` = `base_cat` 10 + object 열 (`:28-42`). 나머지 7열 (`Displaced` · `Educational_special_needs` · `Debtor` · `Tuition_fees_up_to_date` · `Gender` · `Scholarship_holder` · `International`) 은 값이 `yes`/`no`·`male` 같은 글자이고 에이전트 환경은 pandas 2.3.3 (`pip_before.txt`) 이라 object → `cat_cols` 는 대회 설정의 범주 17열과 같음. 처음 판의 "10열" 은 데이터를 안 보고 쓴 것 (틀림)
  - CB·LGB·CBN 의 early stopping (검증 fold 사용, `:285`, `:297`, `:320`): 모델 쪽이라 C1 대상 아님. 에이전트도 "낙관적" 이라고 적음
- R3 판정: (a) 외부 정보·할당 없음. (b) 원본 밖 블록 있음 (파생 7 · 빈도 17). (c) inductive-OK 타깃 독립 블록 남음 (파생 7). → **해당 없음**
- 해석 주의: 최종 점수 (0.5210) 는 블렌드 8 개 + 기하 무게 + 온도를 같은 OOF 로 고른 값이라 낙관적. 파생 7 만의 몫은 따로 안 잼. GBDT 에서 F2 > F0 인지는 실행으로 봐야 함
