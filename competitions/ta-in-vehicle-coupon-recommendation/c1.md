## F2 후보와 뺄 것

- `~f2s` = A + B + C + D (행 단위만). 약 69 열 (C 의 `coupon_frequency` 가 D 와 겹쳐 1 뺌, 실측 필요). 1차 규칙 안 (타깃 비의존, inductive 안)
- `~f2` = `~f2s` + E + F (6 열). 응답자 묶음이 train+test 를 같이 봄 → inductive 밖. F2 로 인정하려면 E·F 를 train 행만으로 다시 fit 해야 함 (train 에 없는 템플릿은 `-1` 또는 `amb` 로 둠)
- 뺄 것:
  - H. `add_stats` (`train.py:26-38`): 응답자 정답 평균 (`person_mean_2/8`, `person_coupon_mean_2/5`) 과 개수. 자기 행을 뺀 LOO 형식. 타깃 의존. `train.py:41-47` 의 `stats=True` 는 `train.py` `__main__` 의 검증 (`stats in [False, True]`) 에만 쓰고, 최종 producer 에서는 호출 안 함 (확인: 최종 producer 목록에 `add_stats` 호출 없음)
  - I. 응답자 × 장소 과거 정답 합 (`second_stage.py`, `coupon_models.py`, `meta_group.py`, `meta_experiment.py`, `coupon_cv.py`): 타깃 의존 history. 최종 제출을 만든 파일 목록에 없음 (도구 트리에 없음)
  - `random_effects.py`, `group_base.py`, `random2.py` (그룹 벌점 로지스틱): 타깃 의존 모델, 최종 체인에 없음
- 해석 주의:
  - B 의 `person` 키는 행 단위로 만들어짐 (fit 없음). 카드 초안의 "train+test 로 응답자 id 를 다시 만듦" 은 부정확: inductive 밖 부분은 E·F (응답자 묶음) 와 레벨 (G)
  - 모든 성분이 같은 A–F 를 받음 → 블록 몫과 모델 몫을 최종 점수에서 가를 수 없음. F2 를 GBDT (CatBoost·LightGBM·XGB) 에 넣어 F0 대비 봄 (C1 규칙 2)
  - 원래 Agent 의 해석 (쿠폰 종류 × 상황 교차, 순서 있는 구간 값) 은 C·D 의 뜻에 해당. 뜻 자체는 옮겨짐
